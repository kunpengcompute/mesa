### 介绍
Mesa 是一个开源的 3D 图形库实现，提供跨平台的 OpenGL、Vulkan 和 OpenCL API 支持。作为 Linux 和其他开源系统的核心图形组件，它充当了硬件图形驱动与图形应用程序之间的桥梁。

### 使用说明
完整指南请查阅文档 (docs/install.rst)，推荐使用 Meson 构建：

```
$ mkdir build
$ cd build
$ meson ..
$ sudo ninja install

```
